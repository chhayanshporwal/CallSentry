# SafeGuard

**Whitelist-based Call & SMS Blocker for Android**

> Only allow calls and messages from people you trust. Block everything else automatically.

## Features

- ✅ Whitelist-only call blocking
- ✅ Whitelist-only SMS filtering
- ✅ Easy contact import from phonebook
- ✅ Blocked call/SMS logs
- ✅ Emergency numbers always allowed
- ✅ PIN protection for settings
- ✅ Material Design 3 UI

## Tech Stack

- **Language:** Kotlin
- **UI:** Jetpack Compose + Material Design 3
- **Database:** Room (local, encrypted)
- **Architecture:** MVVM + Clean Architecture
- **DI:** Hilt

## Requirements

- Android 8.0 (API 26) or higher
- Permissions: Phone, SMS, Contacts

## Building

```bash
./gradlew assembleDebug
```
